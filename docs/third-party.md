# Drittanbieter

Direkte Komponenten: Microsoft Windows App SDK / WinUI (MIT), .NET Runtime (MIT), Entity Framework Core und Microsoft.Extensions.DependencyInjection (MIT), CommunityToolkit.Mvvm (MIT), NAudio (MIT), NuGet.Versioning (Apache-2.0), SQLite (Public Domain), xUnit (Apache-2.0), Inno Setup (eigene freie Lizenz).

Es werden keine fremden Musik-/Naturaufnahmen mitgeliefert. Noise wird mathematisch erzeugt; eigene Audiodateien verbleiben lokal.
